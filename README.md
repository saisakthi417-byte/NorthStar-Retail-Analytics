
# NorthStar Retail Analytics

## Project Overview
NorthStar Retail Analytics is an end-to-end retail analytics project designed to analyse sales, customers, products, returns, inventory, marketing performance and business trends.

The project uses historical retail data from 18 stores across multiple channels to generate actionable business insights and management reports.

## Business Objectives
- Analyse overall sales and revenue performance.
- Understand customer behaviour and segmentation.
- Measure customer retention and repeat purchases.
- Analyse product returns and their financial impact.
- Evaluate marketing campaign performance.
- Monitor inventory and stock availability.
- Analyse sales trends and forecast future demand.
- Build SQL analysis, Excel reports and Power BI dashboards.
- Present findings through an executive management report.

## Setup Instructions

### 1. Clone the repository
```bash
git clone https://github.com/saisakthi417-byte/NorthStar-Retail-Analytics.git
cd NorthStar_Retail_Analytics
```

### 2. Create a virtual environment
```bash
python -m venv .venv
```

### 3. Activate the environment

Windows PowerShell:
```powershell
.venv\Scripts\Activate.ps1
```

### 4. Install dependencies
```bash
pip install -r requirements.txt
```

### 5. Run the project
Refer to the relevant module scripts and execution instructions in the `src/` directory.
